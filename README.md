# STAAR U.S. History stimulus images

Stimulus images (excerpts, photographs, maps, cartoons, charts) cropped from the
2024, 2025 and 2026 released STAAR U.S. History tests, used as the Image Link
for each question in Wayground.

Files are named by test year and question number, for example `2026/q05.jpg`.
Direct link pattern:

    https://raw.githubusercontent.com/kohnhistory/staar-stimuli/main/2026/q05.jpg

Do not rename or move files: the Wayground spreadsheets point at these exact paths.

## Lesson images

`lesson-2000-present/` holds the four graphs and tables used as question images in
the 2000 to Present lesson check-for-understanding set (Q3, Q4, Q7, Q9). These are
original lesson visuals, not released STAAR stimuli.
